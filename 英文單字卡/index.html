📚 英文單字卡

自己造句、語音朗讀、評估熟悉度，優先複習不熟的單字。

先到「同步設定」連接 GitHub，或先用本機暫存模式。
⚙ 同步設定（GitHub JSON）

GitHub Pages 不能直接修改檔案。本頁透過 GitHub Contents API 更新 JSON。Token 只保存在本頁執行期間的記憶體，不寫進 GitHub 或瀏覽器永久儲存。

建議另外建立 Private Repository 存資料，避免單字及評分透過公開 Pages 暴露。不要使用有其他 Repository 權限的 Token；每個裝置需自行輸入。

新增單字

輸入單字後，會自動檢查是否已收錄。

新單字預設熟悉度 4（不熟），後續複習可更新。

每日複習

加權不放回抽樣，單次每個單字最多出現一次；評分越不熟，未來被抽到的機率越高。

這個單字你有多熟？（每次重新評分）

所有單字

    評分與複習次數存在 JSON 資料欄位，不另外顯示成公開表格；目前分數僅在單字清單中供個人確認。

    備份與匯入

    JSON 可下載備份及匯入。離線使用或同步失敗時，請先下載備份，避免遺失新資料。
